Cómo sacar el APK de Zafios II

  1. Entra en el repositorio elplanetadeloszafios2 en GitHub.
  2. Pulsa la pestaña Actions. Si pregunta, acepta activar los flujos de trabajo.
  3. A la izquierda elige Compilar APK y pulsa Run workflow y otra vez Run workflow.
  4. Espera unos 10 minutos hasta que salga el círculo verde.
  5. Vuelve a la portada del repositorio. En la columna derecha, en Releases, abre la última versión y descarga Zafios-II.apk desde el móvil.
  6. Ábrelo en el móvil. Si Android avisa de «origen desconocido», permite instalar desde Chrome o desde Archivos.

Cada vez que subas un El_Planeta_de_los_Zafios_II.html nuevo, GitHub compila el APK solo y lo deja en Releases con un número de versión más.
